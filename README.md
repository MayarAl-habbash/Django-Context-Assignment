# Django Student Identity

A personal student profile website built using Django.

## Features

- Django Templates
- Context Dictionary
- Django Template Filters
- Custom HTML & CSS
- Responsive Design
- CSS Animations
- Static Images

## Technologies

- Python
- Django
- HTML5
- CSS3

## Run the Project

1. Create and activate a virtual environment.
2. Install dependencies:

   pip install -r requirements.txt

3. Run migrations:

   python manage.py migrate

4. Start the server:

   python manage.py runserver
